# 🤲 Gift of the Givers — Humanitarian Relief Platform

An ASP.NET Core MVC web application for managing emergency disaster response, direct donations, and volunteer operations.

## 🛠️ Tech Stack
* **Framework:** ASP.NET Core MVC
* **Database:** Entity Framework Core
* **Styling:** Tailwind CSS

## 🚀 Features
- **Emergency Relief Banner:** Urgent real-time alerts.
- **Disaster Projects:** Campaign progress tracking.
- **Donation Hub:** Support for tax deductible certificates (Section 18A).
- **Operations Dashboard:** Volunteer assignment and project oversight.
